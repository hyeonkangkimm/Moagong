# 🚀 프로젝트 개요

본 프로젝트는 **대용량 데이터 수집·처리 및 실시간 스트리밍 기반 백엔드 아키텍처**를 중심으로 설계된 시스템입니다.
Kafka를 활용한 비동기 메시징 처리와 MongoDB / MySQL을 통한 데이터 저장,
Spring 기반 서버와 Jsoup 크롤링을 결합하여 **확장성과 안정성**을 고려한 구조를 구현했습니다.

## 🛠️ 기술 스택

### 🔧 Backend

* **Java**
* **Spring Framework**
* **Apache Kafka** (비동기 메시지 처리 / 스트리밍)
* **MongoDB** (비정형 데이터 저장)
* **MySQL** (관계형 데이터 관리)
* **Jsoup** (웹 크롤링 및 데이터 수집)

* **Frontend Developer** : 박예지

## ✨ 주요 특징

* Kafka 기반 **비동기 이벤트 처리**
* MongoDB + MySQL **혼합 데이터 저장 구조**
* Jsoup을 활용한 **자동화된 데이터 수집**
* Spring 기반 **확장 가능한 서버 아키텍처**
* 역할 분리가 명확한 **협업 중심 프로젝트 구조**
